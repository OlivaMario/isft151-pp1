# isft151-pp1
Proyecto de Practicas Profesionalizantes 1
Carrera Analista de Sistemas
Programa de inclusión digital bancaria para personas mayores
● No deberán utilizarse ramas de trabajo o “branchs”, a menos que las gestionen correctamente.
● No deben incorporarse archivos de configuraciones específicas de cada integrante.
● No pueden incorporarse archivos binarios y/o dependecias específicas del runtime de trabajo.
● El código del repositorio no debe contener comentarios.
● No podrá emplearse mezcla de idiomas inglés/español. Se trabajará en un único lenguaje de manera consistente
en todo el proyecto.
● Se deberá respetar un mismo estilo de identación fijo. Espacios (3 o 4).
● El encargado del proyecto deberá establecer una convención de codificación: Upper CamelCase, Lower
camelCase, snake_case, etc y deberá mantenerla de forma coherente en todo el proyecto.
